⚡ How to Use Your API Key

Include your generated API key in the x-api-key header with every request to Amygdala:

curl -X POST https://amygdala-api-37nt.onrender.com/v1/auth/signup \ -H "x-api-key: YOUR_API_KEY_HERE" \ -H "Content-Type: application/json" \ -d '{"email":"alice@company.com","password":"securePassword123","turnstileToken":"test"}'
🛡️ Limits: Each project account can create up to 3 API keys utmost. Allowed origins restrict browser CORS access.
📖 Amygdala API Reference & Integration Guide

Amygdala provides high-security authentication-as-a-service with 15-minute RS256 JWTs, refresh token rotation with reuse detection, and OAuth 2.1 with PKCE.

POST/v1/auth/signup — Register user with email, password & turnstile token
// Headers: x-api-key: <key>, Content-Type: application/json // Body: { "email": "user@domain.com", "password": "password123", "turnstileToken": "cf-token" } // Response 200: { "accessToken": "eyJ...", "refreshToken": "...", "user": { "id": "uuid", "email": "..." } }
POST/v1/auth/login — Authenticate with email & password
// Headers: x-api-key: <key>, Content-Type: application/json // Body: { "email": "user@domain.com", "password": "password123" } // If MFA enabled: { "mfaRequired": true, "mfaToken": "eyJ..." } // If normal: { "accessToken": "eyJ...", "refreshToken": "...", "user": { ... } }
POST/v1/auth/refresh — Rotate refresh token (reuse detection)
// Body: { "refreshToken": "..." } // Response 200: { "accessToken": "new-jwt", "refreshToken": "new-refresh-token" }
GET/v1/auth/me — Get current authenticated user profile
// Headers: Authorization: Bearer <accessToken>, x-api-key: <key> // Response 200: { "id": "uuid", "email": "user@domain.com", "email_verified": true, "created_at": "..." }
GET/v1/auth/.well-known/jwks.json — Public JWKS endpoint
// Verify RS256 JWTs locally in your backend using the public key! // Third-party Node.js example: const jwksClient = require('jwks-rsa'); const jwt = require('jsonwebtoken'); const client = jwksClient({ jwksUri: 'https://amygdala-api-37nt.onrender.com/v1/auth/.well-known/jwks.json' }); client.getSigningKey(header.kid, (err, key) => { jwt.verify(token, key.getPublicKey(), { algorithms: ['RS256'] }); });
POST/v1/auth/mfa/enroll & /v1/auth/mfa/verify — TOTP 2FA
// POST /mfa/enroll returns: { "secret": "JBSWY3DPEHPK3PXP", "qrCode": "data:image/png;base64,...", "uri": "..." } // POST /mfa/verify confirms 6-digit code: { "code": "123456" }
🛡️ Two-Factor Authentication (TOTP)

Protect your account using RFC 6238 time-based one-time passwords (compatible with Google Authenticator, Authy, and 1Password).

Password Security

Amygdala uses Argon2id (memoryCost 65536, timeCost 3, parallelism 4), winning the Password Hashing Competition. Raw passwords are never stored or logged.
