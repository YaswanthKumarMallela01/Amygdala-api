Production Auth-as-a-Service Engine

Amygdala is a high-performance, developer-first authentication infrastructure engine. It exposes standardized REST APIs for user signups, credentials login, PKCE OAuth flows, TOTP MFA, automatic refresh token rotation with reuse detection, and cryptographic JWKS verification.

All client requests must be HTTPS and target this cloud root.
🔒 Mandatory Headers
x-api-key: YOUR_API_KEY_HERE Content-Type: application/json
The API key validates your tenant project and CORS rules.
🚀 4-Step Quick Start Guide
1
Generate API Key
From your dashboard, click "+ Create API Key". Store the key in your app's environment as AMYGDALA_API_KEY.
2
Send Auth Request
Call /v1/auth/signup or /login with your key in the x-api-key header.
3
Receive Tokens
Store the 15-minute accessToken in memory, and refreshToken in secure storage.
4
Call Authenticated APIs
Pass Authorization: Bearer <accessToken> to access user profiles or verify JWT locally with JWKS.
💡 Complete Integration Guide (Silent Refresh Pattern)

To integrate Amygdala securely into single-page applications (React, Vue, Next.js, Vanilla JS), use an HTTP interceptor that automatically refreshes expired access tokens without logging the user out.

1. Axios Interceptor Pattern with Refresh Queue
// axiosClient.js - Production Silent Refresh Interceptor import axios from 'axios'; const API_URL = 'https://amygdala-api-37nt.onrender.com'; const API_KEY = 'YOUR_API_KEY_HERE'; export const api = axios.create({ baseURL: API_URL, headers: { 'x-api-key': API_KEY, 'Content-Type': 'application/json' } }); // Attach Access Token to every outgoing request api.interceptors.request.use((config) => { const token = localStorage.getItem('access_token'); if (token) config.headers.Authorization = `Bearer ${token}`; return config; }); // Intercept 401 Unauthorized and silently rotate tokens api.interceptors.response.use( (response) => response, async (error) => { const originalRequest = error.config; if (error.response?.status === 401 && !originalRequest._retry) { originalRequest._retry = true; const refreshToken = localStorage.getItem('refresh_token'); if (!refreshToken) { window.location.href = '/login'; return Promise.reject(error); } try { // Call Amygdala token refresh endpoint const { data } = await axios.post(`${API_URL}/v1/auth/refresh`, { refreshToken }, { headers: { 'x-api-key': API_KEY } }); localStorage.setItem('access_token', data.accessToken); localStorage.setItem('refresh_token', data.refreshToken); originalRequest.headers.Authorization = `Bearer ${data.accessToken}`; // Retry original failed request return api(originalRequest); } catch (refreshErr) { localStorage.clear(); window.location.href = '/login'; } } return Promise.reject(error); } );
2. React / Next.js Auth Hook Pattern (`useAmygdalaAuth`)
// hooks/useAmygdalaAuth.js import { useState, useEffect, createContext, useContext } from 'react'; import { api } from './axiosClient'; const AuthContext = createContext(null); export function AuthProvider({ children }) { const [user, setUser] = useState(null); const [loading, setLoading] = useState(true); useEffect(() => { async function initAuth() { try { const { data } = await api.get('/v1/auth/me'); setUser(data); } catch (e) { setUser(null); } finally { setLoading(false); } } initAuth(); }, []); const login = async (email, password) => { const { data } = await api.post('/v1/auth/login', { email, password }); if (data.accessToken) { localStorage.setItem('access_token', data.accessToken); localStorage.setItem('refresh_token', data.refreshToken); setUser(data.user); } return data; }; const logout = () => { localStorage.clear(); setUser(null); }; return ( <AuthContext.Provider value={{ user, login, logout, loading }}> {children} </AuthContext.Provider> ); } export const useAuth = () => useContext(AuthContext);

🔐 Cryptographic RS256 Verification with JWKS

Amygdala signs access tokens with an asymmetric RSA private key (2048-bit). Your backend services can verify every token in microseconds using the public JWKS without making a database query.

Node.js (jose library) Local Verification
import { createRemoteJWKSet, jwtVerify } from 'jose'; const JWKS_URL = new URL('https://amygdala-api-37nt.onrender.com/v1/auth/.well-known/jwks.json'); const JWKS = createRemoteJWKSet(JWKS_URL); export async function verifyToken(jwt) { const { payload } = await jwtVerify(jwt, JWKS, { issuer: 'amygdala-auth' }); return payload; // { sub, email, name, exp, iat } }
Python (PyJWT) Local Verification
import jwt from jwt import PyJWKClient url = "https://amygdala-api-37nt.onrender.com/v1/auth/.well-known/jwks.json" jwks_client = PyJWKClient(url) def verify_token(token): signing_key = jwks_client.get_signing_key_from_jwt(token) data = jwt.decode( token, signing_key.key, algorithms=["RS256"], issuer="amygdala-auth" ) return data
⚠️ Standard Error Reference

All error responses return a standardized JSON envelope: { "error": "Descriptive message" }.

400
Bad Request — Zod schema validation failed (missing password, malformed email, or invalid payload).
401
Unauthorized — Invalid password, expired RS256 token, revoked refresh token, or invalid x-api-key.
403
Forbidden — Cloudflare Turnstile bot verification failed or CORS origin mismatch for this API key.
409
Conflict — Email already registered under this tenant pool.
429
Too Many Requests — Redis sliding window rate limit exceeded (e.g. max 5 login attempts / 15 mins).
