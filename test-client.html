⚡ Core API Endpoints
POST/v1/auth/signup
Creates a new user. Pass email, password (min 8 chars), and turnstileToken.
POST/v1/auth/login
Authenticates credentials. Returns RS256 accessToken (15m) and refreshToken (2d), or mfaRequired: true.
POST/v1/auth/refresh
Rotates the refresh token with automatic token reuse detection. Returns a new access token.
GET/v1/auth/me
Returns the authenticated user's ID, email, verified status, and creation date.
GET/v1/auth/.well-known/jwks.json
Exposes the public key in standard JWKS format. Third-party backends verify RS256 JWTs locally without hitting the database.

Session Duration: Logged in sessions stay active in your browser for 2 days only. After 48 hours, users are automatically required to sign in again for enhanced security.

Password Encryption: Argon2id memory-hard hashing protects against brute force attacks.
