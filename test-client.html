Authentication-as-a-Service Engine

Amygdala is a high-performance, developer-first authentication backend. It exposes standardized REST APIs for user signups, credentials login, PKCE OAuth flows, TOTP MFA, automatic refresh token rotation with reuse detection, and cryptographic JWKS verification.

🔗 Base URL & Gateway
https://amygdala-api-37nt.onrender.com
All requests must be HTTPS and target this cloud root.
🔒 Mandatory Headers
x-api-key: YOUR_API_KEY_HERE Content-Type: application/json
The API key validates your tenant project and CORS rules.
🚀 4-Step Quick Start Guide
1
Generate API Key
From your dashboard, click "+ Generate Key". Store the key in your app's environment.
2
Send Auth Request
Call /v1/auth/signup or /login with your API key in the x-api-key header.
3
Receive Tokens
Store the 15-minute accessToken in memory, and refreshToken in secure storage.
4
Verify or Call /me
Call /v1/auth/me or verify the RS256 JWT using public JWKS locally.
💡 Complete Integration Guide (Silent Refresh Pattern)

To integrate Amygdala securely into single-page applications (React, Vue, Next.js, Vanilla JS), use an HTTP interceptor that automatically refreshes expired access tokens without logging the user out.

// 1. Unified Authenticated Fetch Wrapper async function apiCall(endpoint, options = {}) { const API_URL = 'https://amygdala-api-37nt.onrender.com'; const API_KEY = 'YOUR_API_KEY_HERE'; let accessToken = localStorage.getItem('access_token'); const refreshToken = localStorage.getItem('refresh_token'); if (!options.headers) options.headers = {}; options.headers['x-api-key'] = API_KEY; if (accessToken) options.headers['Authorization'] = 'Bearer ' + accessToken; let response = await fetch(API_URL + endpoint, options); // If 401 Unauthorized, automatically rotate tokens and retry if (response.status === 401 && refreshToken) { const refreshRes = await fetch(API_URL + '/v1/auth/refresh', { method: 'POST', headers: { 'Content-Type': 'application/json', 'x-api-key': API_KEY }, body: JSON.stringify({ refreshToken }) }); if (refreshRes.ok) { const data = await refreshRes.json(); localStorage.setItem('access_token', data.accessToken); localStorage.setItem('refresh_token', data.refreshToken); options.headers['Authorization'] = 'Bearer ' + data.accessToken; return fetch(API_URL + endpoint, options); } else { // Refresh token expired or revoked - clear tokens and redirect to login localStorage.clear(); window.location.href = '/login'; } } return response; }

🔑 Local JWT Verification via JWKS

Because Amygdala signs access tokens using 2048-bit RS256, your backend microservices can verify tokens locally with zero latency, without querying the database:

// Node.js RS256 Verification with jwks-rsa import jwt from 'jsonwebtoken'; import jwksClient from 'jwks-rsa'; const client = jwksClient({ jwksUri: 'https://amygdala-api-37nt.onrender.com/v1/auth/.well-known/jwks.json', cache: true, rateLimit: true }); function getKey(header, callback) { client.getSigningKey(header.kid, (err, key) => { callback(null, key.getPublicKey()); }); } export function authenticateRequest(token) { return new Promise((resolve, reject) => { jwt.verify(token, getKey, { algorithms: ['RS256'], issuer: 'amygdala' }, (err, decoded) => { if (err) return reject(err); resolve(decoded); // { sub: "user-uuid", email: "...", name: "..." } }); }); }
